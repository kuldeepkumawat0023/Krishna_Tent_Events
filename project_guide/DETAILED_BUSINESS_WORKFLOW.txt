================================================================================
  KRISHNA TENT & EVENTS ERP - DETAILED BUSINESS & OPERATIONAL WORKFLOW
================================================================================
  Business: Krishna Tent & Events (Single Owner ERP)
  Infrastructure: 4 Warehouses / Godowns (Main Godown, Jaipur Godown, 
                 Lighting Godown, Resort Store)
  Backbone Philosophy: 
  WAREHOUSE -> AVAILABLE STOCK -> EVENT BOOKING -> RESERVATION -> LOADING 
  -> DISPATCH -> SITE SETUP -> RETURN -> VERIFICATION -> AVAILABLE AGAIN
================================================================================


================================================================================
1. OVERVIEW & PARALLEL WORKFLOW ARCHITECTURE
================================================================================
The ERP operates on 2 primary parallel workflows:

FLOW A: BUSINESS & WAREHOUSE OPERATIONS (Daily Godown & Inventory Management)
FLOW B: EVENT ORDER & REVENUE LIFECYCLE (Customer Enquiry to Event Closure)

Both flows converge seamlessly at the Stock Ledger and Finance Cashbook levels.

8. DEPARTMENT 7 : EVENT ORDER LIFECYCLE (MAIN REVENUE ENGINE)
================================================================================

[STAGE 1: SALES & CUSTOMER INQUIRY]
  Customer Call / Walk-in
        │
        ▼
  CRM Module -> Create Lead (Customer Name, Phone, Event Date, Event Type)
        │
        ▼
  Schedule Site Visit -> Assign Supervisor
        │
        ▼
  Supervisor visits venue, measures dimensions, notes power/access points

[STAGE 2: QUOTATION & LIVE STOCK CHECK]
  Open Quotation Builder -> Select Event Start & End Dates
        │
        ▼
  Add Items: 500 Chairs, 50 Tables, 1 Tent (100x50 ft), Lighting Package
        │
        ▼
  SYSTEM AUTO-CHECKS LIVE AVAILABILITY ACROSS ALL 4 GODOWNS
  (Ensures items are not already booked/reserved for overlapping dates)
        │
        ▼
  Generate Quotation PDF (Itemized Rates + Transport + Labour + GST)
        │
        ▼
  Send Quotation to Customer -> Customer Approves

[STAGE 3: BOOKING & ADVANCE PAYMENT]
  Click [Convert Quotation to Booking]
        │
        ▼
  Record Advance Payment (e.g. Rs. 50,000 via UPI/Cash)
        │
        ▼
  Booking Status changes to CONFIRMED
        │
        ▼
  Rental Agreement Contract PDF generated & signed
        │
        ▼
  Calendar Widget updated with Event Dates

[STAGE 4: STORE TEAM - MATERIAL RESERVATION & SPLIT]
  System triggers Material Reservation
        │
        ▼
  MULTI-GODOWN AUTO-SPLIT SUGGESTION:
  ├── Main Godown: 300 Chairs, 30 Tables
  ├── Jaipur Godown: 200 Chairs, 20 Tables
  └── Lighting Godown: Full Lighting Package
        │
        ▼
  Store Manager confirms split -> Click [Lock Stock]
        │
        ▼
  Reserved Stock is locked (cannot be booked by any other user)

[STAGE 5: DISPATCH & VEHICLE LOADING]
  Event Date arrives -> Godown Loading Slips generated per godown
        │
        ▼
  Store Team manually verifies items during vehicle loading
        │
        ▼
  Assign Vehicle & Driver (Truck RJ-14-GA-1234, Driver Ramu)
        │
        ▼
  Gate Pass generated -> Status: DISPATCHED -> Material Status: IN-TRANSIT

[STAGE 6: SITE RECEIPT & SETUP EXECUTION]
  Vehicle arrives at Venue -> Supervisor receives material
        │
        ▼
  Click [Confirm Site Receipt] in Mobile/Web UI
        │
        ▼
  On-site setup execution (Tent erection, lighting installation, seating)
        │
        ▼
  Supervisor uploads Setup Photos & logs Site Attendance
        │
        ▼
  Event Live -> Event Concludes

[STAGE 7: PACKING, RETURN & GODOWN VERIFICATION]
  Event Complete -> Supervisor oversees dismantling & packing
        │
        ▼
  Packing Checklist verified -> Loaded back into vehicles
        │
        ▼
  Dispatched back to godowns -> Vehicle arrives at Godown Door
        │
        ▼
  Store Manager receives vehicle & performs RETURN VERIFICATION:
  ├── 480 Chairs GOOD     -> Immediately returned to Available Stock
  ├── 15 Chairs DAMAGED   -> Moved to Repair (Damage charge added to bill)
  └── 5 Chairs MISSING    -> Marked Missing (Cost billed to Customer)
        │
        ▼
  Stock Ledger updated across all godowns

[STAGE 8: FINAL BILLING & P&L CLOSURE]
  Accountant generates Final GST Tax Invoice
  (Base Rental + Damage Charges - Advance Paid = Final Payable)
        │
        ▼
  Record Final Customer Payment
        │
        ▼
  Cashbook & Bankbook auto-updated
        │
        ▼
  SYSTEM CALCULATES EVENT PROFIT & LOSS:
  Total Revenue (Rs. 1,80,000) 
  - Labour Expenses (Rs. 20,000)
  - Vehicle Transport Fuel (Rs. 12,000)
  - Third-party Generator Hire (Rs. 15,000)
  -----------------------------------------
  NET EVENT PROFIT: Rs. 1,33,000
        │
        ▼
  Event Status: CLOSED

10. ROLE-BASED DAILY WORKFLOWS
================================================================================

10.1 OWNER DAILY WORKFLOW
  Morning 9:00 AM:
  - Login -> Dashboard Overview
  - Review Today's Events (4 Events)
  - Review Pending Dispatches (2 Dispatches)
  - Check Stock Alerts (Low Stock warnings)
  - Check Pending Customer Payments & Vendor Dues
  - Review Purchase Requests & Stock Transfer Requests -> Click [Approve]
  
  Evening 6:00 PM:
  - Review Dispatches Completed & Material Returned
  - Review Today's Total Income, Expenses & Net Profit
  - Review Audit Logs
  - Logout

10.2 STORE MANAGER DAILY WORKFLOW
  - Login -> Godown Dashboard
  - Receive incoming vendor purchases -> Create GRN & Update Stock
  - Review today's Material Reservations -> Approve Godown Splits
  - Generate Loading Slips -> Checklist Load Check -> Dispatch Vehicles
  - Receive returning vehicles -> Perform Return Verification
  - Categorize returned items (Good, Damaged, Repair, Missing)
  - Log Repair Requests & Close Godown Day

10.3 SUPERVISOR DAILY WORKFLOW
  - Login -> Receive Assigned Event Tasks
  - Reach Event Venue -> Receive Vehicle & Confirm Site Receipt
  - Oversee Tent & Decor Setup -> Upload Setup Photos
  - Mark Site Staff Attendance
  - Oversee Packing after event -> Verify Return Checklist
  - Dispatch Vehicle back to Godown -> Close Event Task

10.4 ACCOUNTANT DAILY WORKFLOW
  - Login -> Finance Dashboard
  - Record Customer Advance Payments & issue receipts
  - Log Daily Operational Expenses (Labour, Transport, Food)
  - Pay Vendor Dues & update Vendor Ledgers
  - Reconcile Daily Cashbook & Bankbook Entries
  - Generate GST Tax Invoices
  - Generate Monthly P&L, GST Returns & Sales Reports

  CORPORATE / AGENCY PARENT ACCOUNT CREATION
        │
        ▼
  Setup Corporate Account Profile:
  ├── Company Name: Royal Weddings & Events Agency
  ├── GSTIN: 08AAAAA0000A1Z5
  ├── Primary Contact: Vikram Singh (Managing Director)
  ├── Credit Limit Allowed: Rs. 10,00,000
  ├── Payment Terms: 30 Days Net Credit
  └── Special B2B Contract Rate Discount: 15% Off Standard Rental List
        │
        ▼
  MULTIPLE SIMULTANEOUS EVENT BOOKINGS:
  ├── Booking #101: Destination Wedding @ Fairmont Hotel (Dec 12)
  ├── Booking #102: Corporate Gala Dinner @ Marriott (Dec 14)
  └── Booking #103: Sangeet Ceremony @ Leela Palace (Dec 18)

  - System checks total outstanding balance across all 3 active bookings.

    -> SYSTEM TRIGGER: Credit Limit Breached Alert -> Owner Approval Required.
        │

  - Corporate Client sends single lump-sum payment of Rs. 5,00,000 via NEFT.
  - Accountant opens Bulk Payment Allocation Screen:
    ├── Allocate Rs. 2,00,000 to Invoice #101 (Fully Paid)
    ├── Allocate Rs. 1,50,000 to Invoice #102 (Partially Paid)
    └── Allocate Rs. 1,50,000 to Invoice #103 (Advance Received)
