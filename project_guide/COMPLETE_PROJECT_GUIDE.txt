# SECTION 1: SYSTEM OVERVIEW & TECH STACK
################################################################################

Project: Single-Owner Warehouse-Centric Event ERP for Krishna Tent & Events
Warehouses: 4 Godowns (Main Furniture, Jaipur, Lighting, Resort Store)
SaaS/Subscription: NONE (Custom enterprise solution)

Tech Stack:
  - Frontend: Next.js 16 (v16.2.5, App Router) + TypeScript + Tailwind CSS v4
  - Backend: Node.js + Express.js
  - Database: MongoDB + Mongoose ODM (39 Models)
  - Auth: JWT + bcrypt + RBAC (8 User Roles)
  - Storage: Multer + Cloudinary
  - AI Engine: DeepSeek API (Event Theme & Budget Recommendations)
  - Real-time: Socket.io

################################################################################
# SECTION 4: CORE ERP BUSINESS FLOW & LOGIC RULES
################################################################################

Core Philosophy:
  WAREHOUSE → AVAILABLE STOCK → EVENT BOOKING → RESERVATION →
  LOADING → DISPATCH → SITE → RETURN → VERIFICATION → AVAILABLE AGAIN

Strict Business Rules:
  1. No Negative Stock - Prevent inventory going below zero.
  2. Reserved = Locked - Reserved items cannot be booked for another event.
  3. Every Movement = Ledger Entry - Audit trail for all inventory movements.
  4. Partial Dispatch & Partial Return fully supported.
  5. Verification Categories: Good, Damaged, Repair, Missing, Scrap.
  6. Multi-Warehouse Auto Split: Auto-suggest reservation split across 4 godowns.
