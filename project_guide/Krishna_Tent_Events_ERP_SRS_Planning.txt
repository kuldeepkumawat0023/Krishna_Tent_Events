================================================================================
SECTION 1: EXECUTIVE SUMMARY & SYSTEM SCOPE
================================================================================
1.1 PROJECT PURPOSE
Krishna Tent & Events ERP is a warehouse-centric event management system designed 
specifically for single-owner operations. It manages inventory across multiple dynamic godowns, 
tracks live material movement across event execution stages, handles single and corporate 
customer accounts with credit limits, automates financial ledgers (Cashbook/Bankbook), 
and provides real-time business insights to the owner.

1.2 NON-SAAS MANDATE
This system is strictly a single-tenant enterprise solution. It contains:
- NO SaaS multi-company registration or subscription plans.
- NO multi-tenant database partitioning.
- Direct single-owner control with role-based access for staff.

1.3 CORE ERP BACKBONE PHILOSOPHY
Inventory stock availability across multiple physical warehouses directly drives event quotation, 
booking confirmation, multi-godown material reservation, vehicle loading, site execution, 
packing return, godown verification, and financial profit & loss calculation.

SECTION 2: TECHNICAL ARCHITECTURE & TECH STACK
================================================================================
2.1 APPLICATION TECH STACK
- Frontend Framework: Next.js 16 (v16.2.5, App Router) + TypeScript
- Styling & Components: Tailwind CSS v4 + shadcn/ui components
- State & Data Fetching: React Context (Auth/Theme) + SWR Client Hooks
- Backend API Framework: Node.js + Express.js (MVC Architecture)
- Database & ODM: MongoDB + Mongoose ODM (43 Collections)
- Authentication: JWT (JSON Web Tokens) + bcrypt password hashing + HTTP-only cookies
- Storage Service: Multer + Cloudinary (Image & PDF storage)
- AI Intelligence Engine: DeepSeek API (Theme suggestions & budget calculation)
- Real-time Engine: Socket.io (Live stock alerts & dispatch tracking)

2.2 APPLICATION LAYOUT RULE
- 100% Edge-to-Edge Fluid Width (`w-full max-w-full px-4 py-4 md:px-6 md:py-6`).
- NO fixed width caps (`max-w-7xl`).
- Responsive across Mobile (<640px), Tablet (640-1024px), Laptop (1024-1536px), and Ultra-Wide (>1536px).

SECTION 6: SINGLE VS CORPORATE CUSTOMER ENGINE & CREDIT CONTROL
================================================================================
6.1 SINGLE / RETAIL CUSTOMER ENGINE
- Designed for individual clients booking single events (Weddings, Birthdays).
- Isolated single event ledger.
- Account automatically closes upon 100% payment settlement.

6.2 CORPORATE AGENCY & HOTEL ENGINE
- Designed for event planners, corporate houses, and hotels running 5-10 simultaneous monthly events.
- Parent Account Profile features:
  ├── Corporate Credit Limit (e.g., Max Outstanding: Rs. 10,00,000)
  ├── Credit Term (e.g., 30 Days Net Credit)
  └── B2B Contract Rate Discount Tier (e.g., 15% automatic discount on quotations)
- Credit Limit Breach Check: System checks total active balance + new booking amount. If balance > Credit Limit, triggers an alert for Owner Approval.
- Bulk Payment Allocation: Lump-sum payment (e.g., Rs. 5,00,000 NEFT) allocated across multiple active event invoices.
- Consolidated Statement of Account & Aging Report.
